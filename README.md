# فُرص — Team 3 Mega MVP

**Developed by Team 3**

## الجديد في هذه النسخة
- شاشة Loading احترافية تظهر أولًا ثم تنتقل تلقائيًا إلى الصفحة الرئيسية.
- كتالوج كبير جدًا داخل الـMVP (أكثر من 500 عنصر تجريبي).
- أنواع كثيرة: منح، كورسات، تدريبات، مسابقات، ورش، Bootcamps، تدريب عملي، تطوع، تبادل طلابي، بحث علمي، زمالات، هاكاثونات.
- مجالات كثيرة: برمجة، AI، علوم، هندسة، طب، أعمال، اقتصاد، لغات، تصميم، إعلام، قانون، بيئة، علوم اجتماعية، بحث، مهارات مهنية.
- أكثر من 12 لغة في الفلاتر.
- بحث + فلاتر + ترتيب + Pagination.
- حفظ الفرص في LocalStorage.
- صفحة/قسم للتخصصات.
- تصميم Responsive.
- Footer: Developed by Team 3.

## ملاحظة مهمة
الكتالوج الكبير الموجود هنا هو **بيانات MVP/Prototype للتجربة والعرض**، وليس قاعدة بيانات حية تضمن أن كل فرصة ما زالت مفتوحة. قبل نشر فرصة فعلية للطلاب يجب التحقق من موعدها وشروطها من المصدر الرسمي.

## التشغيل
افتح `index.html` مباشرة، أو ارفع الملفات على GitHub Pages / Netlify / Vercel.
