# فُرص — Team 3 Mega MVP

**Developed by Team 3**

## الجديد في هذه النسخة
- شاشة Loading احترافية تظهر أولًا ثم تنتقل تلقائيًا إلى الصفحة الرئيسية.
- كتالوج كبير جدًا داخل الـMVP (9,999 عنصر تجريبي).
- أنواع كثيرة: منح، كورسات، تدريبات، مسابقات، ورش، Bootcamps، تدريب عملي، تطوع، تبادل طلابي، بحث علمي، زمالات، هاكاثونات.
- مجالات كثيرة: برمجة، AI، علوم، هندسة، طب، أعمال، اقتصاد، لغات، تصميم، إعلام، قانون، بيئة، علوم اجتماعية، بحث، مهارات مهنية.
- أكثر من 12 لغة في الفلاتر.
- بحث + فلاتر + ترتيب + Pagination.
- حفظ الفرص في LocalStorage.
- صفحة/قسم للتخصصات.
- تصميم Responsive.
- Footer: Developed by Team 3.

## ملاحظة مهمة
الكتالوج الكبير الموجود هنا هو **بيانات MVP/Prototype للتجربة والعرض**، وليس قاعدة بيانات حية تضمن أن كل فرصة ما زالت مفتوحة. قبل نشر فرصة فعلية للطلاب يجب التحقق من موعدها وشروطها من المصدر الرسمي.

## ❤️ المفضلة
يمكن للطالب الضغط على زر القلب في أي فرصة. يتم حفظ الفرص في LocalStorage، ويوجد رابط **❤️ المفضلة** في شريط التنقل يعرض كل الفرص المحفوظة، مع عداد لعددها. يمكن حذف أي فرصة من صفحة المفضلة.

## صفحة شرح المشروع
تمت إضافة قسم **عن مشروع فُرص** يشرح المشكلة، الحل، المستخدمين، المميزات، تجربة المستخدم والتطوير المستقبلي.
تم حذف قسم **Riskiest Assumption** بالكامل بناءً على الطلب.

## كتالوج 9,999 فرصة
هذه النسخة تحتوي بالضبط على **9,999 فرصة Prototype/Demo** موزعة على عشرات المجالات، 12+ نوع فرصة، و13 لغة، مع بحث وفلاتر ومفضلة وPagination.
البيانات الكثيرة هدفها العرض واختبار الـMVP، وليست قائمة حقيقية تضمن أن كل فرصة مفتوحة حاليًا. يجب التحقق من المصدر الرسمي قبل التقديم.


## 🔗 الربط بالمصادر الحقيقية
هذه النسخة ليست مجرد بيانات ثابتة:
- Backend بـ Node.js + Express.
- Endpoint `/api/opportunities` يسحب كتالوج **Microsoft Learn الرسمي** عبر الـCatalog API.
- يوجد زر/رابط للمصدر الرسمي داخل الفرص الحية.
- تمت إضافة بوابات رسمية لـ **Erasmus+** و **European Youth Portal** كمصادر مباشرة للفرص.
- Endpoint `/api/sync` لإعادة تحديث البيانات من المصدر.
- الكتالوج المحلي 9,999 عنصر يظل كـfallback حتى لا ينهار الـMVP لو المصدر الخارجي غير متاح.

Microsoft Learn يوفر Catalog API رسميًا ويعيد بيانات الوحدات ومسارات التعلم والشهادات والكورسات وغيرها بصيغة JSON. كما أن Erasmus+ وEuropean Youth Portal يوفران بوابات رسمية للفرص الدراسية والتدريبية والتطوع والتبادل.

## 🔗 فتح الفرصة والتقديم
كل فرصة مرتبطة بحقل `sourceUrl`. عند الضغط على **عرض الفرصة ↗** تظهر نافذة بتفاصيلها، وبداخلها زر **اذهب إلى الفرصة الرسمية ↗** يفتح صفحة المصدر في تبويب جديد. كما يظهر رابط المصدر الرسمي مباشرة على البطاقة.


## ✅ النسخة المضبوطة
الآن `index.html` و`style.css` موجودان في نفس المجلد الرئيسي، لذلك يمكنك فتح `index.html` مباشرة وستظهر الواجهة والتصميم.
ولتشغيل الربط الحي بالمصادر الرسمية شغّل:
```bash
npm install
npm start
```
ثم افتح `http://localhost:8080`.

## نسخة التسليم النهائية المصححة
تمت إعادة بناء JavaScript بالكامل في هذه النسخة بدل ترقيع الأجزاء القديمة:
- لا يوجد فلتر لغة.
- الـ9,999 فرصة والـcategories يتم عرضهم محليًا فورًا.
- لا يوجد اعتماد على API أو الإنترنت لفتح الصفحة.
- الـLoading ينتقل تلقائيًا.
- المفضلة، البحث، الفلاتر، التخصصات، عرض الفرصة، والمصدر الرسمي تعمل.

## الروابط الرسمية
تم إصلاح روابط الفرص بحيث كل بطاقة تحتوي على رابط رسمي يعمل.
مهم: الـ9,999 عنصر في نسخة الـMVP هي بيانات تجريبية مولدة وليست 9,999 إعلانًا حيًا تم جمعها من الإنترنت؛ لذلك الرابط يوجه إلى صفحة الكتالوج الرسمية لمقدم الخدمة، وليس إلى صفحة إعلان محدد مخترع. لا يتم اختلاق روابط عميقة لفرص غير موجودة.
